## 🚀 使用指南

### 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt
pip install pytest pytest-cov pytest-timeout hypothesis

# 2. 运行所有测试
python auto_test.py

# 3. 查看测试报告
open htmlcov/index.html  # 覆盖率报告
cat test_report_*.json   # JSON 报告
```

### 开发时测试

```bash
# 快速测试（仅单元测试）
python auto_test.py --quick

# 仅 E2E 测试
python test_e2e.py

# 测试特定功能
python -m pytest test_full.py::TestCryptoBasic -v
```

### 提交前检查

```bash
# 完整测试
python auto_test.py

# 检查覆盖率
python auto_test.py --coverage
```
