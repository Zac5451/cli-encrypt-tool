## 时间对比

```
传统方式：
┌────────────────────────────────────────────────┐
│ 找密码 → 输入密码 → 可能输错 → 重新输入       │
│   5s       10s         5s          10s         │
│                                                │
│ 总计：约 10-30 秒                              │
└────────────────────────────────────────────────┘

生物识别方式：
┌────────────────────────────────────────────────┐
│ 按指纹/看摄像头 → 验证成功                     │
│      1s              1s                        │
│                                                │
│ 总计：约 1-2 秒                                │
└────────────────────────────────────────────────┘

⚡ 效率提升：5-15 倍
```

## 数据流

```
加密时保存密码：
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 用户输入 │───►│ 生成文件 │───►│ 存储到   │───►│ 钥匙串   │
│ 密码     │    │ 标识符   │    │ 钥匙串   │    │ 加密保存 │
└──────────┘    └──────────┘    └──────────┘    └──────────┘

解密时获取密码：
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 检测文件 │───►│ 生成文件 │───►│ 触发生物 │───►│ 获取密码 │
│ 标识符   │    │ 标识符   │    │ 识别验证 │    │ 并解密   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                      │
                                      ▼
                            ┌──────────────────┐
                            │ Touch ID/Face ID │
                            │   用户验证       │
                            └──────────────────┘
```
